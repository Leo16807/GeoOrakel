GeoOrakel ist eine standortbasierte Android-App, die klassische Kartennavigation mit Künstlicher Intelligenz verbindet. Ziel der App ist es, Nutzern, insbesondere Touristen in fremden Städten, auf intuitive und interaktive Weise Informationen über ihre unmittelbare Umgebung zugänglich zu machen.

Kartenansicht: Die App zeigt eine interaktive OSM-Hintergrundkarte, auf der der eigene Standort in Echtzeit angezeigt wird. Die Kartenvisualisierung erfolgt über die MapLibre SDK, während die eigentlichen Kartendaten über die MapTiler API geladen werden. Nutzer können dabei flexibel zwischen verschiedenen Kartenansichten wechseln, etwa einer klassischen Straßenkarte und einer Satellitenansicht, um je nach Bedarf die passende Perspektive auf ihre Umgebung zu erhalten.

KI-Chat: Neben der Kartenansicht steht ein Chat mit einem Large Language Model (LLM) zur Verfügung, zwischen dem und der Kartenansicht frei navigiert werden kann. Die Anbindung des LLM erfolgt über die Google Gemini API. Der eigene Standort kann geokodiert an das LLM übergeben werden. Zusätzlich wird auf die Wikipedia GeoSearch-API zugegriffen. Diese wird angefragt, um passende Wikipedia-Artikel zu nahegelegenen Orten und Sehenswürdigkeiten zu ermitteln. Basierend auf den Koordinaten 1
und den Wikipedia-Artikeln generiert das LLM dann einen kurzen Text, der den Nutzer über die Umgebung informiert. Nach der initialen Vorstellung der Umgebung steht die KI dem Nutzer auch für weiterführende Rückfragen zur Verfügung, etwa zu Öffnungszeiten, Details zu einzelnen Orten oder alternativen Aktivitätsvorschlägen.

Technische Umsetzung: Die App wird nativ mit Android Studio in Kotlin entwickelt. Für das Frontend kommt anstelle klassischer XML-Layouts das moderne Jetpack Compose-Framework zum Einsatz. Da die App auf Standortdaten sowie eine Internetverbindung angewiesen ist, werden die entsprechenden Berechtigungen (Internet- und Standortzugriff) beim App-Start automatisch überprüft. Sollten diese nicht erteilt worden sein, wird der Nutzer entsprechend informiert und erhält die Möglichkeit, die Berechtigungen direkt zu erteilen. Dies wird mit Hilfe der accompanist-permissions-Library von Google umgesetzt.
